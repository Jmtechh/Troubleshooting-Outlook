<h1>Troubleshooting-Outlook</h1>


<h2>Description</h2>
The aim of this lab is to show you how to troubleshoot Outlook not opening due to add-ins.


<h2>Utilities Used</h2>

- <b>Outlook</b>
- <b>Microsoft 365</b>


<h2>Environments Used </h2>

- <b>Windows 10 </b>


<h2>Program walk-through:</h2>

The first thing I did was open up Outlook in safe mode. This is a good troubleshooting practice because it allows you to isolate different applications that may be causing start up issues with Outlook.

<img src="https://i.imgur.com/YF64AzV.png" height="80%" width="80%" alt="Disk Sanitization Steps"/>

Once you are in safe mode you can go to file, options and then go to the add in section.

<img src="https://i.imgur.com/bzYAPB2.png" height="80%" width="80%" alt="Disk Sanitization Steps"/>

Now from here you can remove different add-ins to test to see if one of the add-ins is preventing Outlook from opening.
